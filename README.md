✨ Features

For visitors

- 20+ projects — a growing catalogue of public builds
- Filterable grid — AI, Email, Utility, Bots, and more
- Live preview modal — view project screenshots before opening them
- Real-time Lagos clock — current WAT time
- Auto-updating age — automatically updates every January 8
- Rotating hero headline — intent, purpose, curiosity, precision, and more
- Dark glass aesthetic — animated gradients, blurred panels, and ambient glows
- No visitor login required
- No tracking or cookies
- Mobile-first layout — designed for phones, tablets, and desktops

For developers

- No frameworks — plain HTML, CSS, and JavaScript
- No build step — open "index.html" and it works
- Static-hosting friendly — Vercel, Netlify, GitHub Pages, Cloudflare, and more
- CSS design system — custom properties for colours, spacing, and radii
- Responsive breakpoints — "980px", "760px", and "430px"
- Reduced-motion support — respects "prefers-reduced-motion"
- Semantic HTML — landmarks, ARIA labels, and keyboard support
- Clean JavaScript — modular functions, escaped output, and IntersectionObserver reveals
- Custom 404 and error pages

🚀 Quick Start

For visitors

1. Visit "zikkytech.xo.je" (https://zikkytech.xo.je)
2. Browse the Projects section
3. Select a project to view its preview
4. Open the live project

For developers

git clone https://github.com/zikky0001-droid/zikkytech.git
cd zikkytech

# Open locally — no installation required
open index.html

# Or use a simple local server
npx serve .

No "npm install". No build command. No configuration required.

🔥 Projects, In Detail

🤖 ZIKKY AI — "zikky-ai.xo.je" (https://zikky-ai.xo.je)

A free AI chat platform for conversations, coding help, and additional AI-powered features.

🧠 DEVZIKKY AI — "devzikky.onrender.com" (https://devzikky.onrender.com)

A developer-focused AI assistant designed around technical questions, debugging, programming, and development workflows.

📧 ZMAIL Studio — "zmail.zone.id" (https://zmail.zone.id)

A workspace for creating polished emails with reusable templates, a rich editor, live previews, and a server-side sending API.

📬 ZMAIL Drop — "zmaildrop.vercel.app" (https://zmaildrop.vercel.app)

A public, name-based temporary mailbox service with an API for developer testing and quick-use inboxes.

📮 ZDROPMAIL — "zdropmail.vercel.app" (https://zdropmail.vercel.app)

A separate temporary mailbox service using generated addresses and limited lifetimes.

ZMAIL Drop and ZDROPMAIL serve different use cases: one focuses on public/name-based access, while the other uses generated addresses.

💬 ZQUOTE — "zquote-tau.vercel.app" (https://zquote-tau.vercel.app)

A Telegram-style quote generator API that renders shareable quote images from supplied user and message information.

📚 ZIKKY Manga Hub — "zikkymangahub.onrender.com" (https://zikkymangahub.onrender.com)

A manga-reading project with a dedicated reader interface and additional reader-focused features.

🖩 ZIKKY Calculator — "zikkycal.netlify.app" (https://zikkycal.netlify.app)

The first DEVZIKKY release from 2025 — a compact calculator with a Matrix-inspired visual identity.

💬 ZIKKY Telegram Bot — "t.me/zbot101bot" (https://t.me/zbot101bot)

A Telegram automation project combining utilities, AI features, and bot workflows.

🎯 Phishing Edu — "zikkyphishing.netlify.app" (https://zikkyphishing.netlify.app)

A security-awareness project designed to demonstrate phishing concepts in an educational context.
